⚙ GitHub Sync Settings
Tracker data is saved to data/tracker-data.json in your GitHub repo.

For a private repo, create a Fine-grained PAT at github.com/settings/tokens with these exact settings:
 • Repository access → Only select repositories → pick notice-period
 • Permissions → Contents → Read and write

The token is stored only in your browser (localStorage) and is never committed to the repo.
